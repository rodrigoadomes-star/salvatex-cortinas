# Salvatex Admin — Painel de Pedidos

Documento único da área de pedidos do painel administrativo.

Recursos: lista e busca de pedidos, detalhes completos, alteração de status, rastreio, observações internas, histórico, logs e resumo financeiro.

As observações internas são administrativas e não aparecem para o cliente. O futuro módulo de notificações deverá enviar rastreio primeiro por e-mail e posteriormente também pela API oficial do WhatsApp, ao mudar o pedido para Enviado.
